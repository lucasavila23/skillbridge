# Persona: The Unconnected Student

**SkillBridge — Persona Builder output.** Version 1.1, provisional — 2026-09-17,
evidence review 2026-09-22.
Inputs: [`opportunity.md`](../opportunity.md), [`goals.md`](../goals.md),
[`assumptions.md`](../assumptions.md), [`experiment-card.md`](../experiment-card.md).

Student side of the marketplace — supply side of talent. Per the homework
rule: **only real-user evidence changes this or the Jobs to Be Done
grounding.**

**Evidence review — 2026-09-22:** [UV-S01 and UV-S02](../validation/interviews-2026-09-22.md)
report application requests for examples of delivered work and uncertainty
about what to show. They do **not** establish this persona's defining
claims — year of study, network access, GPA, or rejection rate — so the
persona stays hypothesis-heavy beyond the shared "hard to prove experience"
pain. See [findings](../validation/findings-2026-09-22.md) for the full
claim-level breakdown, and [The Tinkerer](tinkerer.md) for the more detailed
persona built from the same UV-S01 account.

**Ready to prove it — nobody will let them.**

- 2nd–4th-year tech student (software / web / data), solid coursework record
- No internship, no industry network, not in the connected/top-GPA slice that gets pulled in through referrals
- Applying broadly and getting filtered out before ever reaching a human

> "I have the skills. I just don't have the one thing every posting actually wants — proof I've already done it." — illustrative persona voice

**Job to be done:** When I have no internship and no network, I need to accumulate a verifiable record of real, team-delivered client work, so an employer has a reason to trust me before I have any formal experience.

## What we know

| | |
|---|---|
| SUPPORTED | 66.8% of grads name lack of experience as their #1 obstacle; ~35% of "entry-level" postings still ask for 3+ years ([`opportunity.md`](../opportunity.md)) |
| SUPPORTED | Referrals convert 30–60% to interview vs. 0.1–2% for cold applications — this persona is structurally locked out of the channel that actually works ([`opportunity.md`](../opportunity.md)) |
| SUPPORTED | Verified real work beats unverifiable resume claims: employers say skills-based hiring matters, but under 1 in 700 hires actually move on it without proof ([`opportunity.md`](../opportunity.md), HBS/Burning Glass 2024) |
| REPORTED | The founder's own path — rejected everywhere, eventually hired by a startup deliberately recruiting overlooked candidates — is the seed insight for the entire venture ([`opportunity.md`](../opportunity.md)) |
