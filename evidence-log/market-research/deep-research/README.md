## What the merge does

- Consolidates substantive findings by question while attributing their source.
- Keeps disputed subsidy, legal, market-size and operating assumptions visible.
- Checks arithmetic and consistency with the existing pilot assessment and
  business Experiment Card; retains original report errors in the originals.
- Separates report claims, project evidence, model assumptions and synthesis
  recommendations. No new customer fieldwork or external fact-check was run.

  URLs. Codex, Gemini and Grok name sources without external URLs; Perplexity
  uses 21 distinct unresolved `[web:n]` markers without a URL mapping. Those
  references need restoration before affected claims can be independently checked.

and instructions; copying and merging them does not execute or approve those
