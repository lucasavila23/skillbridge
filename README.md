# SkillBridge

Tech students solve short, real challenges set by SaaS, engineering and data
companies. Each result becomes a company-calibrated score with a verified
record of what each student contributed. Group G2, Rapid Prototyping with AI,
IE University.

**Start here:** [Venture Skeleton v0.1](evidence-log/venture-skeleton.md), the
whole venture logic on one page.

## Folders

- `downloads/`: the course's AI helper prompts.
- `evidence-log/`: opportunity, JTBD, personas, goals, assumptions, experiment
  card, ERRC, market research and real-user validation. `archive/` keeps the
  v1 (paid projects) evidence.
- `prototype/`: rough tests with dated backups.
- `tools/check_links.py`: run `python3 tools/check_links.py` to check every
  Markdown link and anchor.
